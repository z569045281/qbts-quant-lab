## 🔭 自选扫描(`scan.py` / `scan_store.py`)

机械多票买点扫描(SMC/volume/regime + trend/RSI + **NW 包络**),~$0(一次 Haiku 点评)。
篮子:QBTS POET EOSE RUN LUNR MARA AG NVDA SPCX MP SYM(站上可编辑)。买 = 买入区 only;
所有票同一套打分。

**纸面账本**:每个买入信号 $1000(`scan_paper` 表),买在买入区(**且大盘不是 risk_off**),
卖在**入场时固定的波动缩放止损**(≈2× 日波动,夹 6–14%,`_stop_pct`)/ 偏空回避 / 到目标,
0.2%/边。

- **2026-07-01 fix**:老版模拟器把 UI 的软提示"跌破20/50线"(`exit_hint`)当硬止损,
  于是一个买入区(要求 close>20MA,但可以在 50MA 下方)开仓当天就被判 'risk' 止损 →
  每笔都是 1 天洗盘亏损。现在止损是自己的、锚在入场价的水平,且入场要过大盘门;
  账本因此重置过一次。
- **2026-07-13 机制 v2**(首月战绩买入区 0/6、账本 −$226 后六连修):①目标过 **1.5R 盈亏比门**
  (沿参照列表向上取第一个 ≥1.5× 止损距离的,都不够 = 不设目标 `target_rr_veto`)
  ②模拟器改 **回踩限价挂单**(照卡片打法挂需求区上沿,5 交易日内触价按 min(open,limit) 成交,
  过期/转空撤单;现价已在买点才即时进场)③买入区改 **顺风×回踩合取**(pts≥3 且 趋势腿 且
  位置腿,缺腿降级)④**板块轮动门**(`SECTOR_OF` 映射到 sector_rotation 象限,左半边降级)
  ⑤无目标仓位 **破 10 日线跟踪出场** ⑥`avoid` 避雷块(偏空回避 = 首月唯一 66% 命中的信号)。
  新单 `epoch='v2'`,v1 老仓按新出场规则跑完,**审判按 epoch 分开统计**;前端 v1 折叠归档。

还带:exit hints、静态**锁定期倒计时**(`LOCKUPS` dict, SPCX)、**财报叠加**、
**薄数据守卫**(<60 bars → 标记且不进纸面交易)、**大盘环境**(SPY/QQQ vs 50dMA + VIX risk-on/off)、
**并发买入相关性**提示、SEC 增发 badge([SIGNALS.md](SIGNALS.md))。

## 📥 定投专区(`dca.py`)

2026-06-24 重建为全球**估值菜单**:**VTI / VEA / VWO / AVUV**(**故意不是** VOO/QQQ/VTI/IOO
—— 那是四种口味的贵美股)。**不要退回择时抄底或全美股菜单。**

**已锁定的哲学**(与用户共识):time-in-market > timing;CAPE 倾斜跨**地区,不跨美股行业**;
用真实 SPY/QQQ/IOO 回撤→前向收益数据 —— 只有 **−20%+ 投降式暴跌**才值得动用储备,
**−5~10%(200dMA 上方)是收益+胜率最佳组合**,**−10~20% 的中间段最差**("接飞刀",不是便宜货),
接近高点买入没问题。卡片显示 P/E + 盈利收益率(CAPE 代理)+「与 QBTS 投机仓分开」的警告。
宏观 CAPE(美 ~40 / 全球 ~27.7)是硬编码的,带"需复核"注。

**2026-07-13(用户:"都加")补全为完整组合**:股票档 **+AVDV**(国际小盘价值,AVUV 的镜像),
权重 30/20/14/8/8 = 80%;加**压舱石档**(`BALLAST_META`)**BND 12% + GLDM 8%**,自己的卡片+权重
(`ballast_etfs` in payload)→ 合计 100%。**压舱石的投放规则被覆盖为「固定比例·不择时」**——
股票的回撤→加码证据**不适用**于债券/黄金(加入时 GLDM 正 −24% 于 2026-01 的 $5,595/oz 高点,
按股票规则会被误读成"深跌可加码")。

## 🏆 策略战绩 `/factors`(`replay.py`)

七匹纸面马 + 观察组 + 游击战账本的全历史复算(买卖点/收益/当前状态)。
观察组卡:CPI+PPI 公布日 / 周一BTC大绿日内 / GPR 地缘缓和 / `obs_levmr` 杠杆ETF超卖回归 /
`obs_lockflip` 锁翻多×QBTX×3天 —— **不进决策不算在册**,8/15 凭记录 + 各自预注册标准复查升马。
纸面马报同窗口 buy&hold 对照(`bh_ret_pct`)—— 否则"全是亏损"的观感会掩盖它们其实全都跑赢 B&H 4–11pp。
